# MarketsView

金融市場のニュースを読み、自分の疑問から因果関係を考え、仮説と反証条件を蓄積する公開学習ノート。

## 方針
- **ニュースの事実**、**メカニズムの解説**、**自分の仮説**、**検証結果**を区別する。
- 毎日の株価・為替・金利・コモディティを「なぜ動いたか」でつなぐ。
- 各仮説には、反証条件と次に観察する指標を書く。
- 記事本文は転載しない。出典URLと自分の要約を記録する。
- 数値は出典・観測日時が確認できるときだけ確定値として記載し、未確認の数字は再検証対象とする。

## ディレクトリ
- `daily/`: 日次市況ノートと翌営業日のシナリオ
- `topics/`: ニュースをきっかけとした疑問・金融知識の整理
- `research/`: 検証したい仮説、データ、反証条件
